## 1. Zero-Bug Manifesto Compliance Matrix
| Bug Flagged in Previous Iteration | BRIDGE Prevention Implementation |
|---|---|
| **Header Button Inconsistency** | Strictly single `HOME` button. No redundant workspace buttons or duplicate icons. |
| **Sidebar Actions Sticking Open** | Hover-only edit/delete (`.histActions { display: none; }`, `.histRow:hover .histActions { display: flex; }`). Fixed 38px `.new` button. |
| **Smart Title Derivation** | Automatically strips conversational preambles ("Can you please", "Kindly migrate", "ji", "hi"). Derives title from schema filename or AI structured topic. |
| **Bulky Findings Boxes** | Replaced the 4 oversized square cards with a sleek, 36px horizontal status ribbon (`.bridgeMetricsStrip`) with glowing indicator dots. |
| **Recent Cards Empty Void** | Cards have compact geometry (`min-height: auto; padding: 14px 16px;`). Snippets prioritize AI summary and never display bare "hi". |
| **Session Persistence** | Never saves empty sessions to `localStorage`. Only saves sessions containing active messages. |
| **Inline Document Viewer** | Instant local blob previews via `URL.createObjectURL(file)`. Single document badge in user bubble with no duplicate open button in AI card. |
| **Typo Interceptor** | Instant guardrail interceptor for greetings/typos (`"ji"`, `"hi"`, `"helo"`), returning a friendly agent intro without calling Bedrock. |

## 2. API Endpoints Reference
- `GET /api/health` — Agent health check and capability probe (HTTP 200).
- `POST /api/migrate` & `POST /api/bridge/migrate` — Multipart form-data or JSON payload schema analysis and migration generation.
- `GET /api/document/{filename}/view` — Secure browser viewer (inline PDF or HTML rendering for Excel/Word/CSV/JSON).
- `GET /api/document/{filename}` — Original document download.

## 3. Core Deliverables Generated by BRIDGE
1. **Migration Readiness Score (0–100):** Algorithmic feasibility metric.
2. **Schema Mapping Matrix:** Explicit source field vs target field with data type conversion rules.
3. **Target Ingestion Payload:** Production-ready headless CMS JSON with one-click copy.
4. **Exceptions & Risk Log:** Critical/Warning/Suggestion issues with actionable remediation steps.
